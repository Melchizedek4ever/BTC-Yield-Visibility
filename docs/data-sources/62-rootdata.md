# RootData

**Tier:** 5 — Fundamentals/research (optional)
**Category:** Fundamentals (funding, team, ecosystem mapping)
**Adapter kind:** n/a
**Status:** not recommended now

## What it is

Web3 project/funding intelligence platform — VC rounds, investor data, team
track records, ecosystem maps (confirmed to include a dedicated Stacks
ecosystem project list).

## Why it's interesting, why not now

Funding/backer quality is a legitimate Counterparty Risk signal (a
protocol backed by known, reputable investors vs. anonymous team is
meaningfully different risk) and its Stacks ecosystem map could help
*discover* new protocols to onboard as adapters, beyond the 11 already
curated. But this is a one-time research/discovery tool, not a live data
feed our pipeline needs to poll.

## Recommendation

Skip as an adapter target. Useful to browse by hand when scouting the next
protocol to add to `lib/protocols.ts` — not a source that belongs in
`adapters/`.
